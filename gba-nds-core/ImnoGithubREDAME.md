GBA + NDS Core

A JavaScript-based Game Boy Advance and Nintendo DS emulator core prototype.

Features

- GBA ROM loading
- NDS ROM loading
- GBA cartridge header reader
- Nintendo DS cartridge header reader
- ARM7TDMI CPU skeleton
- ARM9 CPU skeleton
- ARM7 CPU skeleton
- Memory subsystem prototypes
- Browser-based interface
- GitHub Pages compatible
